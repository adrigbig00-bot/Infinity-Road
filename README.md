# Infinity Road

🎮 [**ИГРАТЬ СЕЙЧАС!**](https://adrigbig00-bot.github.io/Infinity-Road/)

## О проекте
Это моя первая опубликованная игра. Я создал её в Godot, чтобы научиться разработке и пройти полный цикл создания игры — от идеи до релиза.

### Основные механики
- **Основная механика 1:** Езда на машине
- **Основная механика 2:** Бесконечный спавн дорог
- **Основная механика 3:** (В разработке) Прокачка машины

## Как играть
- **Управление:** W A D (вперёд, влево, вправо)
- **Цель игры:** Доезжать до контрольных точек и прокачивать машину

## Технологии
- Godot Engine 4.x
- GDScript
- DeepSeek (ассистент для сложного кода)
- GitHub Pages (хостинг)

## Что я сделал сам
- Весь геймдизайн и концепция игры
- Программирование игровых механик
- Публикация и настройка хостинга

## Что я делал не сам
